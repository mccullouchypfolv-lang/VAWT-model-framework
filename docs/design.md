# 阶段一：2D-to-1D FiLM-FNO

用户选择的骨干：输入 [B,20,C,Nθ] 的 LF 截面场与全局工况，输出 [B,Nθ,2]，通道顺序 Cp_ref、Cq_ref。工况为 TSR、参考风速、弦长、厚度比。第一阶段推理仍需要 LF 截面场，不是仅由几何参数直接预测。

高度为非周期域，先反射延拓后作二维频谱卷积，随后裁剪；方位角不填充，保留周期拓扑。每块为谱卷积加点式线性跳跃，经 FiLM 调制和 GELU。并联局部高度卷积分支补充短尺度特征，保留正负高度频率。输出高度场和可复用的整机方位角特征；不保证与尚未定义的后续 FM 模型权重完全兼容。

层高与方位角坐标显式输入。以归一化层宽权重聚合高度，直接进入 Cp/Cq 预测头；主网络不包含移相插值或相位融合。默认两通道独立预测，用物理一致性软损失 Cp=TSR*Cq。这样保留 Cp/Cq 各自评估，也暴露二者代数冗余。

默认输入采用 Cn_radial、Ct_tangential、Cl_AR、relative_velocity_m_s、当地风速、local_tsr。坐标单独传递，不参与训练统计。输入不含整机标签。基线由同样的 Ct、相对速度及全局弦长重建截面转矩，并核验导出的 torque_Nm_per_m。LF 截面载荷与整机标签可能近似确定性积分，因此必须同时报告物理积分基线，避免将聚合重建误认为 LF 精度提升或 HF 泛化证据。

严格检查状态、有限值、20×160 网格、坐标及系数关系。失败工况剔除并记录原因；完整工况划分，默认 geometry_id 分组，避免同一几何跨集合。仅训练集拟合标准化。数据源目录及 common_config 必须固定，不自动混用不同求解版本；数据源内容哈希写入缓存清单。

损失：标准化曲线 MSE、周期中心差分误差、周期均值误差、原始系数空间物理一致性误差。评估 MAE/RMSE、峰值与均值误差及前六阶谐波幅值误差。模型配置、标准化、划分、优化器和最佳验证模型均保存；测试集只在训练选择完成后评价。

验证：数据坏样本、行顺序、划分隔离、训练集统计、两方向频谱梯度、FiLM 条件梯度、高度聚合直接接入预测头、输出与可迁移特征、损失反传、短训练与保存加载一致性。物理基线单独核验原求解器的叶片移相。真实 LF 小样本执行冒烟训练，不把短训练指标解释为正式精度。

物理边界：周期 FFT 不消除有限模态截断/混叠误差。LF 没有真实三维信息时，不能声称自动识别展向诱导或叶尖涡效应。高度延拓只是数值边界处理。
